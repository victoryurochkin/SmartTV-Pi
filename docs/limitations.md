# Ограничения

- Pi 3B/3B+ имеет 1 ГБ RAM. Цель вывода 1080p не гарантирует воспроизведение защищённого видео 1080p. Для тяжёлых сайтов снизьте качество в плеере, для HEVC используйте Pi 4 либо локальную копию в H.264. **[НЕ ПРОВЕРЕНО НА УСТРОЙСТВЕ]**.
- Для H.264 на Pi 3B+ производитель указывает 1080p30. Проверяйте 1080p60 на конкретном файле. Аппаратные лицензии MPEG‑2 и VC‑1 для Pi 3 привязаны к серийному номеру. Для универсального образа предусмотрено программное воспроизведение таких файлов по возможностям платы. [Документация Raspberry Pi](https://www.raspberrypi.com/documentation/computers/config_txt.html).
- На Pi 4 целевой 4K60 подключается через HDMI0. Для старого ТВ или нестабильного кабеля выберите 1080p. HDR10, EDID, HDCP и passthrough зависят от цепочки вывода. **[НЕ ПРОВЕРЕНО НА УСТРОЙСТВЕ]**.
- Google документирует вход по коду и Cast для поддерживаемого приложения YouTube. Если `youtube.com/tv` перенаправляет в обычную версию или не показывает код, используйте веб-версию. Для гарантированной поддержки Cast нужен сертифицированный приёмник. [Вход в приложение](https://support.google.com/youtube/answer/3015415) · [Управление с телефона](https://support.google.com/youtube/answer/7640706).
- Доступность сервиса определяется правообладателем, регионом, подпиской и устройством. Матрица [совместимости](compat.md) отделяет ограничения из справок от фактических результатов.
- Pi 5 вне приёмки. На нём H.264 декодируется программно. **[НЕ ПРОВЕРЕНО НА УСТРОЙСТВЕ]**.
- В тестовом выпуске обновление выполняется записью нового образа на вторую карту. Откат — загрузка с сохранённой карты. Встроенная OTA, автономная установка с USB и автоматический A/B-откат остаются открытыми.
- Экранный мастер настраивает Wi-Fi, региональные параметры и PIN. Временная точка доступа, настройка композита из интерфейса и интерактивное Bluetooth-сопряжение с экранным вводом кода оставлены для следующих этапов. Стандартные настройки экрана и звука доступны в Kodi.
- Телефон вводит печатные символы английской раскладки. PIN на плитках ограничивает доступ из лаунчера. Фильтрация содержимого зависит от настроек аккаунта провайдера и сети.
- Для панели нужна локальная IPv4-сеть с адресами RFC 1918. VPN и маршрутизация по доменам, TVHeadend, AirPlay, Chromecast-приёмник, отдельные плагины радио и подкастов и сервер Samba остаются за пределами тестового выпуска.
