# Совместимость веб-сервисов

Оценка дана для штатного Chromium Raspberry Pi OS в Cage. `НП` во всех столбцах означает **[НЕ ПРОВЕРЕНО НА УСТРОЙСТВЕ]**. Порядок значений: открытие / вход / воспроизведение / качество. Во всех плитках по умолчанию стандартный User-Agent Chromium. Разрешение из справки провайдера не является результатом на Pi.
